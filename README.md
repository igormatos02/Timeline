# Chrono Timeline - Vertical Timeline Web Application

Uma aplicação web moderna e elegante para gestão e visualização de linhas temporais verticais com nó de acompanhamento diário.

![Timeline Screenshot](./docs/preview.png)

## 🌟 Destaques & Funcionalidades

- **Interface Vertical Decrescente**: O dia de hoje (**HOJE**) surge no topo da linha temporal, descendo cronologicamente para os dias anteriores.
- **Nós de Acompanhamento Diário**: Cada dia do intervalo possui uma bolinha visual no eixo central.
- **Multi-Timeline Manager**: Crie e alterne entre múltiplas linhas temporais (*Lançamento de Produto, Redesign, Infraestrutura, etc.*).
- **Cartões de Eventos Interativos**: Títulos, horário, prioridades (*Urgente, Alta, Média, Baixa*), checklist de tarefas com alternância em tempo real e tags.
- **Filtros e Pesquisa**: Busca por palavra-chave ou `#tag`, filtragem por status (*Em Progresso, Concluído, Planeado*) e alternância para ocultar dias vazios.
- **Design System Premium**: Tema escuro glassmorphic com efeitos de iluminação, animações com Framer Motion e suporte a cores personalizadas por timeline.

## 🛠️ Tecnologias Utilizadas

- **React 18**
- **Vite**
- **Vanilla CSS** (Design System com Glassmorphism, CSS Variables e HSL Palette)
- **Framer Motion** (Animações suaves de timeline e modais)
- **Lucide React** (Ícones modernos)
- **Date-fns** (Manipulação e formatação de datas)

## 🚀 Como Executar Localmente

1. **Clonar o repositório**:
   ```bash
   git clone <URL_DO_REPOSITORIO>
   cd Timeline
   ```

2. **Instalar as dependências**:
   ```bash
   npm install
   ```

3. **Iniciar o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

4. Acesse a aplicação no navegador em `http://localhost:5173`.
